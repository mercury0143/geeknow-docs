## 模型分组

| 模型系列 | 页面 | 说明 |
| --- | --- | --- |
| MiniMax H3 | [概览](/api-reference/videos/minimax-h3/overview) | 普通档 `minimax-h3-768p` / `minimax-h3-2k` 使用 `503`；Pro 档 `minimax-h3-pro-768p` / `minimax-h3-pro-2k` 使用 `913` 并支持参考视频 |
| manxue-2.5 | [概览](/api-reference/videos/manxue-2.5/overview) | JSON 请求；仅支持参考生视频；使用 `seconds`、`ratio` 和 `images` 数组 |
| mini-2.0 | [概览](/api-reference/videos/mini-2.0/overview) | JSON 请求；使用 `duration`、`ratio`、固定 `resolution: "480p"` 和可选 `images` 数组 |
| Wan 3.0 | [概览](/api-reference/videos/wan3/overview) | 通义万相 `wan3.0-video` / `wan3.0-video-prime`，使用 `seconds`、`size`、`aspect_ratio`、`image`、`images` 和 `metadata` |
| Grok | [概览](/api-reference/videos/grok/overview) | `grok-imagine-video`、`grok-imagine-video-1.5-preview` |
| Sora | [概览](/api-reference/videos/sora/overview) | `sora-2` |
| Veo | [概览](/api-reference/videos/veo/overview) | `veo_3_1`、`veo_3_1-fast` |
| 国产视频模型 | [概览](/api-reference/videos/aigc/overview) | `Vidu`、`Kling`、`Hunyuan`、`Mingmou`、`OS`、`GV`、`Hailuo`、`SV`、`JV` |
| 特惠渠道系列 | [概览](/api-reference/videos/special-offer/overview) | `manxue-2.0` |
| Seedance 2.0 | [概览](/api-reference/videos/seedance-2/overview) | `doubao-seedance-2-0-260128`、`doubao-seedance-2-0-fast-260128` |
| Seedance 1.5 | [概览](/api-reference/videos/seedance/overview) | `doubao-seedance-1-5-pro_480p`、`doubao-seedance-1-5-pro_720p`、`doubao-seedance-1-5-pro_1080p` |
