# manxue-2.5 视频

`manxue-2.5` 是独立的视频生成系列，使用 `POST /v1/videos` 创建异步任务，使用 `GET /v1/videos/{task_id}` 查询任务状态，并可通过 `GET /v1/videos/{task_id}/content` 下载生成结果。

该系列采用 `/v1/videos` 的 `multipart/form-data` 请求，普通参数通过表单字段传入，参考图片通过重复的 `images` 字段上传。

## 模型与规格

| 项目 | 规则 |
| --- | --- |
| 模型名 | `manxue-2.5` |
| 创建任务 | `POST /v1/videos` |
| 查询任务 | `GET /v1/videos/{task_id}` |
| 下载内容 | `GET /v1/videos/{task_id}/content` |
| 请求格式 | `multipart/form-data` |
| 时长字段 | `seconds`，支持 `5`、`10`、`30` 秒 |
| 画幅字段 | `ratio`，支持 `1:1`、`3:4`、`4:3`、`9:16`、`16:9`、`21:9` |
| 参考图 | 重复的 `images` 字段，最多 `30` 张 |

## 支持能力

| 能力 | 字段 | 说明 |
| --- | --- | --- |
| 文生视频 | `prompt` | 只传文本提示词即可创建任务 |
| 多参考图 | `images` | 通过重复的表单字段上传图片，约束主体、角色、产品、场景或风格 |

## 请求体边界

- `model` 固定传 `manxue-2.5`。
- `seconds` 仅支持 `5`、`10`、`30` 秒，表单值建议按字符串传入。
- `ratio` 支持 `1:1`、`3:4`、`4:3`、`9:16`、`16:9`、`21:9`。
- 参考图片通过 `images` 文件字段上传；本地文件可直接随 multipart 请求提交。
- `images` 字段可以重复传入多张参考图片，最多 `30` 张。
