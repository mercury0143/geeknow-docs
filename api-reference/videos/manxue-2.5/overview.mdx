# manxue-2.5 视频

`manxue-2.5` 当前仅支持参考生视频：必须提供至少一张参考图，模型根据参考图中的主体、角色、产品或场景生成视频。它不支持纯文生视频、首帧生视频、首尾帧或参考视频/参考音频输入。

接口使用 `POST /v1/videos` 创建异步任务，使用 `GET /v1/videos/{task_id}` 查询状态，并可通过 `GET /v1/videos/{task_id}/content` 下载结果。

## 模型与规格

| 项目 | 规则 |
| --- | --- |
| 模型名 | `manxue-2.5` |
| 创建任务 | `POST /v1/videos` |
| 查询任务 | `GET /v1/videos/{task_id}` |
| 下载内容 | `GET /v1/videos/{task_id}/content` |
| 请求格式 | `application/json` |
| 时长字段 | `seconds`，仅支持 `30` 秒 |
| 画幅字段 | `ratio`，支持 `1:1`、`3:4`、`4:3`、`9:16`、`16:9`、`21:9` |
| 参考图字段 | `images`，必填，最多 `30` 张 |

## 支持能力

| 能力 | 是否支持 | 请求方式 |
| --- | --- | --- |
| 参考生视频 | 支持 | `images` 传入 1 到 30 张参考图，`prompt` 描述动作和镜头 |
| 纯文生视频 | 不支持 | 不要省略 `images` |
| 首帧/首尾帧 | 不支持 | 不提供 `first_image`、`last_image` 等专用字段 |
| 参考视频 | 不支持 | 不提供 `referenceVideos` |
| 参考音频 | 不支持 | 不提供 `referenceAudios` |

## 请求体边界

- `model` 固定传 `manxue-2.5`。
- `prompt` 必填，建议明确描述主体动作、镜头运动、风格和参考图的使用方式。
- `seconds` 仅支持 `30` 秒，不能传入其它时长。
- `ratio` 支持 `1:1`、`3:4`、`4:3`、`9:16`、`16:9`、`21:9`。
- `images` 必填且最多 `30` 张。数组顺序就是参考图顺序。
- `images` 数组成员可使用公网图片 URL，或使用纯 Base64 字符串；不要传 `data:image/...;base64,...` 形式的 data URI。
- 参考图中的角色、产品和场景需要在 `prompt` 中说明，避免被误解为首帧或尾帧约束。
