## 共用接口

```http
POST /v1/videos
```

两个系列都使用 `multipart/form-data`，参考图文件字段为 `input_reference`。直接调用 API 时，建议使用具体 Pro / Max 档位模型；基础模型名更适合在客户端兼容层中映射。
