# Grok Video 1.5

`grok-video-1.5` 系列使用 `multipart/form-data` 创建异步视频任务。该系列包含基础模型名和两个固定时长档位：

- `grok-video-1.5-pro`：固定 `10s`。
- `grok-video-1.5-max`：固定 `15s`。
- `grok-video-1.5`：基础模型名；如需兼容该写法，建议在客户端侧按 `seconds` 映射到 Pro / Max 后再请求。

直接调用 API 时，建议提交具体档位模型。不同账号或分组的可用模型以实际渠道配置为准。

## 方法与路径

```http
POST /v1/videos
```

## 模型与时长

| 提交模型 | `seconds` | 说明 |
| --- | --- | --- |
| `grok-video-1.5-pro` | `10` | 固定 10 秒 |
| `grok-video-1.5-max` | `15` | 固定 15 秒 |
| `grok-video-1.5` | `10` / `15` | 基础模型名；客户端兼容层可分别映射为 Pro / Max |

## 请求格式

使用 `multipart/form-data`。文本字段放入表单字段，参考图通过 `input_reference` 文件字段上传。

| 场景 | `input_reference` 规则 |
| --- | --- |
| 文生视频 | 不传图片；是否可用取决于当前渠道 |
| 首帧生视频 | 传 1 张图片 |
| 首尾帧 | 按顺序传首帧、尾帧 |
| 参考生视频 / 多图参考 | 当前最多传 1 张参考图 |

## 请求示例

<RequestExample>

```bash Pro 10s cURL
curl -X POST https://www.geeknow.top/v1/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=grok-video-1.5-pro" \
  -F "prompt=让参考图中的人物自然转头看向镜头，背景保持柔和景深" \
  -F "aspect_ratio=16:9" \
  -F "seconds=10" \
  -F "size=720P" \
  -F "input_reference=@reference.png"
```

```bash Max 15s cURL
curl -X POST https://www.geeknow.top/v1/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=grok-video-1.5-max" \
  -F "prompt=从首帧自然过渡到尾帧，保持主体身份一致和镜头连贯" \
  -F "aspect_ratio=16:9" \
  -F "seconds=15" \
  -F "size=720P" \
  -F "input_reference=@first-frame.png" \
  -F "input_reference=@last-frame.png"
```

```python Python
import requests

with open("reference.png", "rb") as f:
    resp = requests.post(
        "https://www.geeknow.top/v1/videos",
        headers={"Authorization": "Bearer YOUR_API_KEY"},
        data={
            "model": "grok-video-1.5-pro",
            "prompt": "让参考图中的主体产生轻微动作，固定镜头，无文字",
            "aspect_ratio": "16:9",
            "seconds": "10",
            "size": "720P",
        },
        files={"input_reference": ("reference.png", f, "image/png")},
        timeout=60,
    )

print(resp.json())
```

</RequestExample>

## Body

<ParamField body="model" type="string" required>
模型名称。建议直接传 `grok-video-1.5-pro` 或 `grok-video-1.5-max`。如需兼容 `grok-video-1.5`，请在客户端侧按 `seconds` 解析到具体档位。
</ParamField>

<ParamField body="prompt" type="string" required>
视频生成提示词。
</ParamField>

<ParamField body="aspect_ratio" type="string">
尺寸比例。常见值包括 `2:3`、`3:2`、`1:1`、`16:9`、`9:16`。
</ParamField>

<ParamField body="seconds" type="integer">
目标秒数。`grok-video-1.5-pro` 固定为 `10`，`grok-video-1.5-max` 固定为 `15`。
</ParamField>

<ParamField body="size" type="string">
分辨率档位，常用值是 `480P`、`540P`、`720P` 或 `1080P`。
</ParamField>

<ParamField body="input_reference" type="file">
参考图文件（二进制）。首帧生视频传 1 张；首尾帧按顺序传首帧、尾帧；参考生视频/多图参考场景当前最多传 1 张。
</ParamField>

## Response

<ResponseField name="id" type="string">
任务 ID。
</ResponseField>

<ResponseField name="task_id" type="string">
任务 ID。部分响应会同时返回 `id` 与 `task_id`。
</ResponseField>

<ResponseField name="model" type="string">
任务对应的模型名。部分渠道可能返回归一化后的模型名。
</ResponseField>

<ResponseField name="status" type="string">
任务状态，常见值有 `queued`、`processing`、`completed`、`failed`、`cancelled`。
</ResponseField>

<ResponseField name="progress" type="integer">
进度百分比。
</ResponseField>

## 接入建议

- 客户端应使用创建响应中的 `id` 或 `task_id` 查询任务。
- 不要把 Base64 字符串放进 `input_reference`；multipart 模式需要上传图片二进制。
- 当前渠道下，如果文生视频返回“该模型不支持文生视频”，请改用参考图输入或切换到支持文生的模型/渠道。
