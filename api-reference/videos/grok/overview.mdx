# Grok 视频

Grok 视频系列统一使用 `POST /v1/videos` 创建异步任务，并使用 `GET /v1/videos/{task_id}` 查询状态。开发者接入时需要先区分两条请求形态：

- `grok-video-3-pro` / `grok-video-3-max` 使用 `multipart/form-data`；参考图通过重复的 `input_reference` 文件字段上传。
- `grok-imagine-video` / `grok-imagine-video-1.5-preview` 使用 `application/json`；`grok-imagine-video` 通过 `image` 或 `images` 传入参考图，`grok-imagine-video-1.5-preview` 当前仅建议使用单张 `image`。
- 两类模型共用 `model`、`prompt`、`seconds`、`aspect_ratio` 等字段，但清晰度字段不同：Grok Video 使用 `size`，Grok Imagine 使用 `resolution`。

## 支持模型

| 模型 | 请求格式 | 时长规则 | 参考图规则 |
| --- | --- | --- | --- |
| `grok-video-3-pro` | multipart | 固定 `10s` | 支持多张参考图，建议按实际场景控制数量 |
| `grok-video-3-max` | multipart | 固定 `15s` | 支持多张参考图，建议按实际场景控制数量 |
| `grok-imagine-video` | JSON | 自定义秒数，最小 `1s` | 单图传 `image`，多图传 `images` |
| `grok-imagine-video-1.5-preview` | JSON | 自定义秒数，最小 `1s` | 当前仅建议传 1 张参考图 |

## 常见能力

| 能力 | 传参方式 | 说明 |
| --- | --- | --- |
| 文生视频 | 仅传文本字段 | 不需要上传参考图 |
| 首帧生视频 | `input_reference` 传 1 张图 | 适用于 `grok-video-3-pro` / `grok-video-3-max` |
| 首尾帧 | `input_reference` 依次传首帧、尾帧 | 适用于 multipart Grok Video 系列 |
| 参考生视频 | 重复传 `input_reference` | `grok-video-3-pro` / `grok-video-3-max` 支持多图参考 |
| Grok Imagine 图生视频 | JSON `image` 或 `images` | 单图用 `image`；多图用 `images`，其中 `grok-imagine-video-1.5-preview` 当前仅建议传 1 张 |

## 参数约束

| 字段 | 可用值 | 说明 |
| --- | --- | --- |
| `aspect_ratio` | Grok Video 常用 `2:3`、`3:2`、`1:1`、`16:9`、`9:16`；Grok Imagine 支持常见比例和 `数字:数字` 自定义比例 | 建议显式传入目标比例 |
| `size` | `480P`、`540P`、`720P`、`1080P` | 仅适用于 `grok-video-3-pro` / `grok-video-3-max` |
| `resolution` | `480P`、`720P` | 仅适用于 `grok-imagine-video` / `grok-imagine-video-1.5-preview` |
| `seconds` | Grok Video 使用 `10` 或 `15`；Grok Imagine 使用大于等于 `1` 的整数秒 | `grok-video-3-pro` 固定 `10s`，`grok-video-3-max` 固定 `15s` |
| `prompt` | 字符串 | Grok Imagine 系列建议控制在 `4096` 字符以内；长提示词可能导致上游创建任务失败 |
