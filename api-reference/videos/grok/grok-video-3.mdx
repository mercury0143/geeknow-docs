# Grok Video 3

Grok Video 3 系列使用 `multipart/form-data` 创建异步视频任务。当前文档只列出可直接调用的固定时长模型：

- `grok-video-3-pro`：固定 `10s`。
- `grok-video-3-max`：固定 `15s`。

创建任务后，请使用响应里的 `id` 或 `task_id` 查询任务。不要用响应里的 `model` 字段拼接查询地址或判断任务唯一性。

## 方法与路径

```http
POST /v1/videos
```

## 模型与时长

| 提交模型 | `seconds` | 说明 |
| --- | --- | --- |
| `grok-video-3-pro` | `10` | 固定 10 秒 |
| `grok-video-3-max` | `15` | 固定 15 秒 |

## 请求格式

使用 `multipart/form-data`。文本字段放入表单字段，参考图通过 `input_reference` 文件字段上传。

| 场景 | `input_reference` 规则 |
| --- | --- |
| 文生视频 | 不传图片 |
| 首帧生视频 | 传 1 张图片 |
| 首尾帧 | 按顺序传首帧、尾帧 |
| 参考生视频 / 多图参考 | 可重复传 `input_reference`，建议按实际生成需求控制数量 |

## 请求示例

<RequestExample>

```bash Pro 10s 文生 cURL
curl -X POST https://www.geeknow.top/v1/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=grok-video-3-pro" \
  -F "prompt=城市天台日落延时摄影，云层快速流动，暖色电影感" \
  -F "seconds=10" \
  -F "aspect_ratio=16:9" \
  -F "size=720P"
```

```bash Max 15s 首帧 cURL
curl -X POST https://www.geeknow.top/v1/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=grok-video-3-max" \
  -F "prompt=让参考图中的人物转头看向镜头，背景保持自然景深" \
  -F "seconds=15" \
  -F "aspect_ratio=16:9" \
  -F "size=720P" \
  -F "input_reference=@first-frame.png"
```

```bash 多图参考 cURL
curl -X POST https://www.geeknow.top/v1/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \

  -F "prompt=参考多张图片的主体特征，生成一段连贯的产品展示视频" \
  -F "seconds=15" \
  -F "aspect_ratio=16:9" \
  -F "size=720P" \
  -F "input_reference=@reference-1.png" \
  -F "input_reference=@reference-2.png" \
  -F "input_reference=@reference-3.png"
```

resp = requests.post(

        "aspect_ratio": "16:9",
        "seconds": "10",
        "size": "720P",
    },

print(resp.json())

## Body

<ParamField body="model" type="string" required>
模型名称。可用值为 `grok-video-3-pro` 或 `grok-video-3-max`。
</ParamField>

<ParamField body="prompt" type="string" required>
视频生成提示词。
</ParamField>

<ParamField body="aspect_ratio" type="string">
尺寸比例。常见值包括 `2:3`、`3:2`、`1:1`、`16:9`、`9:16`。
</ParamField>

<ParamField body="seconds" type="integer">
目标秒数。`grok-video-3-pro` 固定为 `10`，`grok-video-3-max` 固定为 `15`。
</ParamField>

<ParamField body="size" type="string">
分辨率档位，常用值是 `480P`、`540P`、`720P` 或 `1080P`。
</ParamField>

<ParamField body="input_reference" type="file">
参考图文件（二进制）。可重复传递多次，对应多张参考图。
</ParamField>

## Response

<ResponseField name="id" type="string">
任务 ID。
</ResponseField>

<ResponseField name="task_id" type="string">
任务 ID。部分响应会同时返回 `id` 与 `task_id`。
</ResponseField>

<ResponseField name="model" type="string">
任务对应的模型名。该字段用于展示和排查，不应用作任务 ID。
</ResponseField>

<ResponseField name="status" type="string">
任务状态，常见值有 `queued`、`processing`、`completed`、`failed`、`cancelled`。
</ResponseField>

<ResponseField name="progress" type="integer">
进度百分比。
</ResponseField>

## 接入建议

- 客户端应使用创建响应中的 `id` 或 `task_id` 查询任务。
- 不要把 Base64 字符串放进 `input_reference`；multipart 模式需要上传图片二进制。
